🆘 PROBLEMAS COMUNS
================================================================================

"CondaError: Run 'conda init' before 'conda activate'"
  → Use run.bat ou run.ps1 em vez de conda activate
  → Esses scripts usam o caminho direto do Python

"ModuleNotFoundError: No module named 'flask'"
  → Verifique se as dependências foram instaladas:
     C:\Users\andre\miniconda3\envs\chat_sd\Scripts\pip list
  → Se não estiverem, instale:
     C:\Users\andre\miniconda3\envs\chat_sd\Scripts\pip install -r requirements.txt

"Porta 5001 já em uso"
  → netstat -ano | findstr :5001
  → taskkill /PID <número> /F

"Arquivo não encontrado"
  → Certifique-se que está na pasta: d:\Program_boy\Github\Chat_SD
  → Use cd para navegar até lá

"Interface em branco"
  → Verifique se os arquivos existem:
     ✓ frontend/index.html
     ✓ frontend/style.css
     ✓ frontend/client_app.js
