# Documentação de Apresentação

Esta pasta organiza a explicação do projeto em peças curtas, pensadas para consulta rápida antes da apresentação.

Use assim:

1. `04-conceitos-fundamentais.md` para começar do zero, com analogias simples.
2. `00-roteiro.md` para a narrativa principal da apresentação.
3. `01-arquitetura.md` para entender os pilares técnicos e os fluxos.
4. `02-perguntas-e-respostas.md` para dúvidas prováveis da banca.
5. `03-guia-de-leitura-do-codigo.md` para localizar rapidamente onde cada comportamento está implementado.

Se aparecer uma nova dúvida durante a preparação, a ideia é criar uma nova seção ou um novo arquivo dentro desta pasta, sempre separado por tema.
